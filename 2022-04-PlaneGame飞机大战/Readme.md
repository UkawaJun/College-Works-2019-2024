# 飞机大战 · pygame 入门作

> 大一、刚学 Python 头一年写的小游戏(2021 年前后)。
> 一个用 pygame 做的纵版飞机大战,纯学习性质——这是我真正意义上的第一个 Python 项目。

参考了经典的 pygame 入门教程(《Python 编程:从入门到实践》里的射击游戏案例)起步,在它的基础上自己改了很多:加了敌机 AI、护盾、最高分存档、星空背景等。代码保留原样,包括当年中英混杂的命名和边学边写的注释——它就是个学习记录。

> 说明:写这个之前,我高三学过 C#,所以不是零基础编程,但确实是零基础 Python。这也是为什么入门作里就敢用类、敢在教程基础上大改。

## 玩什么

一个纵版飞机大战:开始界面点按钮进入,操控飞机躲避并击落敌机,有护盾和计分,通关 / 失败后会记录最高分。

**操作**

- 方向键:移动飞机
- 空格:发射子弹
- F1 / S:功能键
- 关闭窗口退出

## 实现了什么

跟着教程起步,但这些是自己加 / 改的:

- **开始界面**:`Button` 类做的可点击开始按钮;
- **玩家与敌机**:基于 pygame `Sprite`,敌机带简单 AI(`plane_updata`)会自己移动、射击;
- **子弹系统**:发射、上限控制、与敌机的碰撞检测;
- **护盾**:`protect` / `protect2`,被击中时的保护逻辑;
- **最高分存档**:`highscoreR` / `highscoreW` 读写 `data.txt`,关掉游戏分数也留着;
- **星空背景**:`stars` 类铺背景;
- **帧数 / 节奏控制**。

## 运行

```bash
pip install pygame
python pygame2.py
```

(最高分存在同目录的 `data.txt`,首次运行如果没有这个文件,建一个填初始分即可。)
