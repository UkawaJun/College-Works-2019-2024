# EngineTC · 一个 turtle 2D 图形引擎

> 大二刚学 Python 几个月时写的练手项目,从 2022 年 3 月断断续续做到 2022 年底。
> 用 Python 自带的 `turtle` 从零实现的一个 2D 图形 / 运动引擎,纯学习性质。

## 它能做什么

最终版(0.93)里实现了这些,全部手写、不依赖任何第三方库:

- **渐变球体**:用同心圆叠加模拟光源照射的明暗渐变;
- **运动学**:带初速度和加速度的位移积分、圆周运动;
- **图形类系统**:`Graph` 类封装了方块 / 圆 / 点 / 线等图形;
- **嵌套群组**:结构可以层层嵌套,父对象移动时子对象跟随联动;
- **对象追踪**:一个对象可以缓动着去追另一个对象;
- **时间系统**:带暂停功能,且暂停不会让计时出现误差;
- **辅助**:自绘坐标系、实时 FPS 显示、按键交互(`t` 暂停 / `x` 退出)。

| 版本 | 日期 | 做了什么 |
|---|---|---|
| 原型 | — | 用参数方程绘制图形,模拟颜色渐变 |
| 0.80 | 2022.3 | 打包代码,球的颜色自定义,模拟光源照射效果 |
| 0.83 | 2022.3 | 颜色渐变改成反比例函数模式 |

| 0.89 | 2022.3 | 加坐标轴显示;绘制改为瞬间完成,模拟逐帧 |
| 0.896 | 2022.3 | 新的"原子"绘制模式,自适应尺寸,大幅提速 |
| 0.90 | 2022.3 | 删除旧绘制模式,程序轻量化,引入新的定义域应用 |

| 0.912 | 2022.4 | 添加运动相关功能,改善时间计量方式 |

- 组合运动、弹性势能、引力场

## 运行

```bash
python "EngineTC 0.93.py"
```

需要支持图形界面的环境(turtle 依赖 Tkinter)。运行后按 `t` 暂停时间、`x` 退出。
